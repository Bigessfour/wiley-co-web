## 3. Architecture summary

```
Clerk browser
  -> Blazor WASM  http://127.0.0.1:5230     (this Mac, launchctl)
  -> API          http://127.0.0.1:5231     (this Mac, launchctl)
  -> Postgres     mr-storage:5433           (Synology, database wileyco_dev)
        trust boundary: Tailscale

Town Hub cards (browser opens these; this API does not proxy them)
  -> Apartments   http://mr-storage:8082    (NAS, no TLS)
  -> TIKR         http://mr-storage:8080    (NAS, no TLS)
  -> Trash Truck  https://main.d2dke4s7zyafra.amplifyapp.com
  -> Rural Water  (no URL)

Removed, still named in README, handbook, and CI
  Amplify d2ellat1y3ljd9, App Runner wiley-widget-api,
  Aurora wiley-co-aurora-db, Cognito us-east-2_DmY7BCBIp,
  custom host wileywidget.townofwiley.gov
```

Single points of failure: this Mac (client and API), Tailscale, and the one Synology Postgres instance. Trust boundaries: browser to API on loopback; browser to NAS apps over plain HTTP on the tailnet; Trash Truck over HTTPS on the Town Amplify app.
